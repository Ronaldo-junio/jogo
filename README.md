# 🎮 MMO Econômico - Jogo Online Multiplayer

Um jogo MMO com sistema econômico completo, comercio interno, fabricação de itens, e possibilidade de monetização real.

## 🎯 Features Principais

- **Sistema de Economia Dinâmica**: Mineração, agricultura, pecuária
- **Comercio P2P & Mercado Oficial**: Compra/venda de itens e materias primas
- **Fabricação de Itens**: Crafting com receitas balanceadas
- **Sistema de Armas**: Diferentes tipos de armas com materias primas específicas
- **PvE & Monstros**: Combate contra monstros para drops de materias
- **Conversão Real Money**: Trocar moeda virtual por real (com validações de segurança)
- **Multiplayer Online**: Jogadores interagindo em tempo real

## 📁 Estrutura do Projeto

```
jogo/
├── backend/              # Node.js API + WebSocket
├── frontend/            # React + WebGL
├── database/            # Scripts SQL
├── docs/                # Documentação
└── render.yaml          # Configuração Render
```

## 🚀 Stack Tecnológico

- **Backend**: Node.js, Express, Socket.io
- **Frontend**: React, WebGL, Phaser (opcional)
- **Database**: PostgreSQL
- **Deploy**: Render.com
- **Auth**: JWT + OAuth2
